# Ikon & logo Panel Admin
Ganti berkas dengan **nama yang sama**. Ikon menu memakai satu warna (mengikuti warna teks menu), jadi gambar dengan satu warna (hitam) dan latar transparan.

| Berkas | Dipakai untuk | Ukuran tampil | Ukuran SVG saran |
|---|---|---|---|
| logo.svg | Logo sidebar dan layar login | 38 x 38 px | 48 x 48 (persegi) |
| favicon.svg | Ikon tab browser | 16-32 px | 48 x 48 |
| favicon-16/32/48.png | Ikon tab (cadangan) | 16 / 32 / 48 px | sama dengan nama |
| favicon-180.png | Ikon layar utama iOS | 180 x 180 px | sama dengan nama |
| favicon-192.png, favicon-512.png | Ikon aplikasi Android | 192 / 512 px | sama dengan nama |
| dash, orders, box, money, tag, star, editor, gallery, gear, logout, bell, ext, menu, chev (.svg) | Menu sidebar, bilah atas, tombol | 20 x 20 px | 24 x 24 |

Setelah mengganti berkas, tekan Ctrl+F5.
